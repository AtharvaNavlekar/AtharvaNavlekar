I'm a **Full Stack Developer** based in Mumbai with hands-on experience building scalable web applications, designing intuitive interfaces, and architecting end-to-end product solutions. I work across the full stack — from crafting pixel-perfect frontends to designing robust backend APIs and database schemas.
